IMPORTANT -- please read this chart's README.md "Known Limitations" section:
  * NOT PRODUCTION READY: verified manually with k3d, but not yet via the real GitHub Actions
    "ct install" CI pipeline, and ISO loop-mount support is unverified.
  * The "cobblerd" container runs privileged, as root, by design (ISO loop-mount support).
  * Cobbler cannot signal or restart DHCP/DNS/TFTP sidecar Pods in Kubernetes; leave
    manage_dhcp_v4/manage_dhcp_v6/manage_dns/manage_tftpd disabled unless you have your
    own reload mechanism for those sidecars.
  * This chart requires Kubernetes >= 1.29 (native sidecar container support).
